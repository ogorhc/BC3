## 1.0.1

### Patch Changes

- 1744c5a: Fix ~D hierarchy reconstruction for Presto 8.7 files (numeric dotted chapter codes and large integer performance values).

  Two bugs in `looksLikeChildCode()` caused incorrect tree building for FIEBDC-3/2002 files generated by Presto 8.7:
  - **Bug A**: Chapter codes like `2.2`, `2.10` were rejected by a decimal-number regex, misclassified as percentage codes, and orphaned as root nodes. A file with 1 expected root produced 44 roots.
  - **Bug B**: Large integer performance values (e.g. `6990`, `1173`) matched a 4+-digit numeric rule and were treated as child concept codes, producing `BC3_D_MISSING_CHILD_CODE` warnings and corrupting decomposition triplets.

  The fix adds an `inPerfSlot` context parameter to `looksLikeChildCode`. In the performance slot, all numeric strings are rejected (they are always quantities). In the lookahead position, all dotted strings are accepted as potential concept codes.

  After the fix: 0 diagnostics, correct root count, and all children parsed on the Zorrozaurre sample file.

  - **15 record-type parsers** covering all observed FIEBDC-3/BC3 record types (~V through ~G) with full domain model integration
